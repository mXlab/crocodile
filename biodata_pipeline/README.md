# Biodata Pipeline - Emotion Recognition

> **For AI Assistants**: This pipeline processes physiological data to recognize emotions.
> Key implemented modules: Module 2 (Data Slicer), Module 3 (Feature Extractor)
> See docs/implementation/ for detailed technical reports.

## Quick Context

- **Status**: Modules 2 & 3 complete, Module 4 next
- **Language**: Python 3.10+
- **Key Dependencies**: numpy, pandas, scipy, sklearn
- **Data**: CSV files with [heart, gsr, respiration, emotion, feeling_it]
- **Output**: physiological features → emotion classification
